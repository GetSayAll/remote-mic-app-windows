# Windows 音频端点状态未及时刷新

## 复现

- 连接 RC001。
- 在连接页选择一个 Windows 输出端点（例如扬声器）。
- 切换到权限页。
- 预期：音频端点状态显示已就绪。
- 实际：权限页仍显示“待选择输出端点”。

## 日志与证据

- `App.vue` 原先只在首次挂载时调用一次 `getRuntimeSnapshot()`。
- `PermissionsPage.vue` 的状态直接读取启动时的 `runtime.platform.wasapiReady`。
- 连接页选择端点后虽已更新后端快照，但权限页没有新的 runtime 数据。

## 根因

运行时快照在 App 层是一次性读取，跨页面状态因此可能陈旧。

## 修复

App 层每秒刷新一次运行时快照，并在卸载时清理定时器。页面仍可通过各自的实时快照轮询保持更细粒度状态。

## 验证

- 自动化：前端类型检查、单元测试和生产构建通过。
- 真机：待下一版 Draft 在 Windows 上选择端点后切换到权限页确认状态在 1 秒内变为“WASAPI 已就绪”。
