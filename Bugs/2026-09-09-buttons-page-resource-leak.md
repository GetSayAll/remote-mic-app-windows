# 按键页面异步卸载后残留监听器与轮询

- 发现日期：2026-09-08
- 状态：已修复
- 影响范围：无线麦 SayAll Windows 版；与 RC001/RC003 型号无关
- 功能点：按键映射页面生命周期
- 现象：按键页面初始化尚未完成时切换到其他页面，迟到的异步初始化仍会注册 Tauri 事件监听器、轮询定时器和尺寸观察器；重复触发后资源会累积。
- 复现条件：让按键映射配置或事件订阅异步调用保持未完成，卸载按键页面，再让异步调用返回。
- 正常预期：页面卸载后不得创建新资源；已经发起但迟到返回的订阅必须立即取消。
- 证据：`ButtonsPage.test.ts` 的生命周期回归测试分别覆盖初始加载期间卸载、事件订阅期间卸载；修复前控制流会越过卸载清理继续注册资源。
- 根因：`onMounted` 在多个 `await` 之后无卸载状态检查，而 `onUnmounted` 只清理当时已经写入局部句柄的资源。迟到返回的句柄没有后续清理机会。
- 修复：增加组件卸载状态门控和幂等资源清理；每个异步订阅返回后再次检查生命周期，若页面已卸载则立即调用其取消函数。
- 验证：按键页面定向 Vitest 14/14 `passed`；完整本地门禁结果见修复提交和 PR。该问题不依赖真实遥控器，RC001/RC003 真机语音与按键链路未因本修复重新验收，状态为 `deferred`。
