# 按下高亮时序不一致：卡片比连线慢、松开后卡片残留（2026-10-13 现场反馈）

- 发现日期：2026-10-13
- 状态：已修复（自动化 + 浏览器预览逐帧实测 `passed`；真机复看 deferred）
- 影响范围：0.8.6 本地测试构建（`eabd8b7`，RC003 会话）；只影响按键映射页「按下高亮」
  的观感与可测性，不影响按键事件、映射动作或捕获链路
- 功能点：按键映射页按下高亮（卡片 / SVG 连线 / 锚点）+ 高亮时序日志
- 现象（用户原话）：高亮效果"有时候很快，有时候有延迟，有时候卡片和线条不一起高亮"
- 复现条件：按键映射页（「全按键支持」开或关都成立），按遥控器任意键，尤其**快速点按**
  （现场实测按住时长 min 99ms / p50 151ms / max 241ms）
- 正常预期：按下即亮、松开即灭；卡片、连线、锚点在同一帧内一起变化
- 证据：
  1. 引擎侧无延迟：现场日志中 RC003 助手 `[EDGE]` → 主程序 `map_edges` 的间隔
     1–55ms（p50 29ms，无 >55ms 的离群），按下/松开成对（175/175），`map_fire`
     紧跟按下沿（0–1ms）——延迟不在捕获与映射段。
  2. 前端逐帧实测（`vite` 预览 + 逐帧读 `getComputedStyle`，模拟 150ms 短按）：
     - 连线（`path`/`polygon`）：4ms 即到完整按下色（`stroke rgb(239,148,32)`）；
     - 卡片：0→67→101→134→**151ms** 才到 `rgba(239,148,32,0.14)`（160ms 过渡），
       松开后到 **~200ms** 才退回中性色；
     - 锚点：60ms 过渡。
- 根因：同一"按下"状态在三个元素上用了三种时序（`styles.css`：`.mapping-card`
  `transition: background/border-color/box-shadow 0.16s`、`.anchor-dot`
  `transition: opacity 0.06s`、连线无过渡）。短按时卡片来不及画到完整按下色（而连线
  已经是完整按下色）→ "卡片和线条不一起高亮"；连按时卡片还留着上一轮的余色，
  单按时又要等 160ms → "有时快、有时慢"。
- 修复（`7957d12`）：
  - `src/styles.css`：去掉 `.mapping-card` 与 `.anchor-dot` 的过渡——按下/松开是跟随
    物理按键的状态，必须与连线同帧；hover/选中一并即时，避免同一张卡出现两种时序。
  - `src/pages/ButtonsPage.vue`：每次按下/松开各落一行前端日志
    `frontend event=button_edge phase=completed result=passed reason=pressed|released
    detail=<语义键名> elapsed_ms=<收到边沿→下一帧>`。此前"引擎→前端→出画面"整段没有
    日志，这类时序问题只能靠反复试错；现在与 `map_edges` 按时刻对齐即可把延迟拆成
    设备→引擎 / 引擎→前端 / 前端出画面 三段。
- 验证：
  - 自动化：`vitest run` **293 passed | 11 skipped**（新增用例「按下/松开边沿必须落
    `button_edge` 日志」，修复前红：未落日志）、`vue-tsc --noEmit` 通过。
  - 实测（同一测量脚本，阳性对照 = 修复前）：改后卡片/连线/锚点在**同一帧**内亮灭
    （首个采样帧 ≤7ms；松开后第一个采样帧即回中性色）。
  - 真机复看：**deferred**——需装新本地测试包后目视（含快速连按 5–10 次）。
- 隐私检查：记录与日志字段只有语义键名与耗时，无设备身份、个人路径、语音内容或凭据。

## 追加（同日晚，用户二次反馈）：配了映射的键"不能同灭"

- 现象：未配置映射的键按下/松开**同亮同灭**（上一节修复后）；**配置了映射**的键松开后
  卡片区域还亮着，不能与连线一起灭。
- 根因：动作触发反馈（`firedFlash` → `.mapping-cell.flashed` 的按下色底 + `.mapping-card.flashed`
  的 2px 描边）用的是**固定 600ms** 定时器：松开后按下高亮同帧熄灭，而闪烁反馈继续亮到
  手势触发后 600ms（比按下多约 400ms）。
- 修复（`b3c321e`，`src/pages/ButtonsPage.vue`）：闪烁起点 = 手势触发、**终点 = 同键的松开沿**；
  极短按（<150ms）补足到最短可见时间 150ms；600ms 只作"松开沿丢失"（断连/异常）时的兜底；
  按住连发每拍重新起算（`endFiredFlash`）。
- 验证：新增用例「闪烁反馈跟随松开沿」——修复前红（实测松开后 **608ms** 才熄灭），
  修复后绿（松开后 ≤150ms 熄灭，且不在同帧瞬灭）；全前端 `vitest run` **294 passed | 11 skipped**、
  `vue-tsc --noEmit` 通过。真机复看随下一包（配了映射的键：按下即亮、松开全灭）。
