## 要验什么

「按住连续触发」是按键级显式开关（单击 / 长按槽位二选一，双击不参与）：

- 开在**单击**：按住连续触发单击动作（无双击时 0.35 秒起拍；有双击时按住超过
  0.3 秒即确认为单击并起拍，快速点按仍判双击）。
- 开在**长按**：长按动作 0.55 秒触发一次后按该键间隔继续续拍。
- 仅**返回 / 方向 / 音量+ / 音量−** 可开启；只对**可连续执行**的动作生效
  （单键、滚动、鼠标移动；组合快捷键、打开应用、聚焦输入框、鼠标点击只执行一次）。
- 「单击连续」与「长按动作」**互斥**：配置长按动作时开关自动关闭并提示。

自动化已覆盖：状态机时序（确认/续拍/释放/复位）、数据迁移（v0→v1）、界面开关与
互斥提示、类型检查与构建。本手册只验真机与第三方应用可见效果。

## 前置条件

- RC001 或 RC003 已配对并连接；应用为包含本功能的构建。
- 记事本（或可输入文本的目标）打开作为观察窗口。
- 返回 / 音量键需先在按键页开启「全按键支持」（每次开启都会弹一次系统授权）。
- 可读取诊断日志（默认日志目录或 `SAYALL_GATT_LOG` 指定路径）。

## 用例

**E1 · 单击槽位连续触发（无双击）**
配置：返回键（或方向键）单击=「Delete」，不配置双击/长按，开关开在单击。
步骤与判据：点按一次 → 删除 1 个字符；按住 ≥1 秒 → 约 0.35 秒起连续删除；松开立即停、无粘键。
日志：`map_repeat start … trigger=single interval_ms=50` → `map_repeat end … reason=release beats=N`。

**E2 · 长按槽位连续触发**
配置：返回键 单击=「Delete」、长按=「Backspace」，开关开在长按。
判据：点按 → 删除一次；按住 → 约 0.55 秒退格 1 次，随后按约 50ms 间隔连续退格；松开即停。
日志：`map_repeat start … trigger=long` 与逐拍 `map_fire … trigger=long`。

**E3 · 双击共存（开关开在单击 + 双击）**
配置：返回键 单击=「Delete」、双击=「Space」，开关开在单击。
判据：快速双击 → 空格；单次点按 → 约 0.3 秒后删除；按住 → 约 0.3 秒时删除一次并开始连续；
该次按住松开后立刻再点按，不得误判为双击（按新序列的单击处理）。

**E4 · 不可连续执行的动作**
- 单击=「Ctrl+C」：开关置灰并给出原因；按住只复制一次、不重复。
- 长按=「打开应用」且开关开在长按：按住只打开一次应用，不重复启动。

**E5 · 键范围负例**
确定键 / 主页键等：编辑区不显示「按住连续触发」开关；按住不产生连续触发
（配置了长按也只触发一次）。

**E6 · 互斥（界面强制）**
开关开在单击后，再为该键配置长按动作 → 开关自动关闭并就地提示（如「如需长按后继续
连续，请在长按列开启」）；长按动作已存在时到单击列开开关 → 被阻止并提示改用长按列。

**E7 · 回归**
双击判定、锁定动作（Win+L 等释放后执行）、语音键生命周期（按下开始/松开结束、
不参与双击/长按延迟）、快速连按均与升级前一致。

**E8 · 边界**
按住期间断开遥控器 / 系统睡眠 / 退出应用 → 无粘键、无迟到连续拍；
闲置后首次按压（冷态）仍能正常起拍与连续。日志应出现
`map_repeat end … reason=reset|reconfigure` 且之后无该键的 `map_repeat`/`map_fire`。

**E9 · 升级迁移**
用含本功能之前的版本写下配置（例如返回键 单击=「Delete」且按住会连续），升级后打开
按键页：该键开关显示为**开**、按住行为与升级前一致；组合键旧配置（如 单击=「Ctrl+C」）
不再连续（**有意修正**，见 ATTRIBUTION 2026-10-05 记录）。

## 失败处置

| 现象 | 先看什么 |
| --- | --- |
| 按住完全不连续 | 该键是否有事件（返回/音量键需先开启「全按键支持」）；日志有无 `map_fire`/`map_inject` 逐拍记录；开关是否真的为「开」 |
| 连续一拍后就停 | `release` 边沿是否提前到达（粘键/迟滞）；日志 `map_repeat end` 的 reason 与 beats |
| 按一下出两次 | 该键是否走了泄漏对冲路径且动作与原生相同；对照 `map_skip_inject` 记录 |
| 开关置灰/被阻止 | 按键是否在范围内、动作是否可连续执行、该键是否已配长按动作（界面提示即原因） |
| 升级后行为与旧版不一致 | 打开 `button-mappings.json` 检查 `schemaVersion` 与 `holdRepeat`；组合键不再连续属有意修正 |
