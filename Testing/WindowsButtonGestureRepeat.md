> 适用：2026-10-05 起的本地测试包/安装版；**RC001 与 RC003 分别执行**。

## 要验什么

「按住时连续执行」是按键级的 **radio 三选一**（双击不参与），显示在单击、长按两个
编辑页底部，两页是同一个状态：

- **关闭**：按住只执行一次（默认）。
- **重复单击动作**：单击立即执行后连续（无双击时 0.35 秒起拍；有双击时按住超过
  0.3 秒即确认为单击并起拍，快速点按仍判双击）。
- **重复长按动作**：长按动作 0.55 秒执行一次后，按该键间隔继续续拍。
- 控件只出现在**返回 / 方向 / 音量+ / 音量−**；只对**可连续执行**的动作可选
  （单键、滚动、鼠标移动；组合快捷键、打开应用、聚焦输入框、鼠标点击只执行一次）。
- 单击与长按并存时「重复单击动作」不可选，原因直接指向「重复长按动作」；
  已选目标因配置变化不再可用时自动回到「关闭」并提示（不偷改选择）。

自动化已覆盖：状态机时序（确认/续拍/释放/复位）、数据迁移（v0→v1）、界面三态可用性
与原因、自动收口提示、类型检查与构建。本手册只验真机与第三方应用可见效果。

## 前置条件

- RC001 或 RC003 已配对并连接；应用为包含本功能的构建。
- 记事本（或可输入文本的目标）打开作为观察窗口。
- 返回 / 音量键需先在按键页开启「全按键支持」（每次开启都会弹一次系统授权）。
- 可读取诊断日志（默认日志目录或 `SAYALL_GATT_LOG` 指定路径）。

## 用例

**E1 · 重复单击动作（无双击）**
配置：返回键（或方向键）单击=「Delete」，不配置双击/长按，组里选「重复单击动作」。
步骤与判据：点按一次 → 删除 1 个字符；按住 ≥1 秒 → 约 0.35 秒起连续删除；松开立即停、无粘键。
日志：`map_repeat start … trigger=single interval_ms=50` → `map_repeat end … reason=release beats=N`。

**E2 · 重复长按动作**
配置：返回键 单击=「Delete」、长按=「Backspace」，组里选「重复长按动作」。
判据：点按 → 删除一次；按住 → 约 0.55 秒退格 1 次，随后按约 50ms 间隔连续退格；松开即停。
日志：`map_repeat start … trigger=long` 与逐拍 `map_fire … trigger=long`。

**E3 · 双击共存（重复单击动作 + 双击）**
配置：返回键 单击=「Delete」、双击=「Space」，组里选「重复单击动作」。
判据：快速双击 → 空格；单次点按 → 约 0.3 秒后删除；按住 → 约 0.3 秒时删除一次并开始连续；
该次按住松开后立刻再点按，不得误判为双击（按新序列的单击处理）。

**E4 · 不可连续执行的动作**
- 单击=「Ctrl+C」：进单击页 → 「重复单击动作」置灰，悬停与常驻行给出原因；按住只复制一次。
- 长按=「打开应用」：进长按页 → 「重复长按动作」置灰并给出原因；按住只打开一次应用。

**E5 · 键范围负例**
确定键 / 主页键等：编辑区不显示该选项组；按住不产生连续执行（配置了长按也只执行一次）。

**E6 · 并存与变更收口**
① 已配长按动作时进单击页 → 「重复单击动作」置灰，原因写「…请选“重复长按动作”」，
可直接改选「重复长按动作」；
② 选好「重复单击动作」后再为该键配置长按动作 → 自动回到「关闭」并提示
（提示给出下一步：请选“重复长按动作”），长按动作可连续时「重复长按动作」随即可选。

**E7 · 回归**
双击判定、锁定动作（Win+L 等释放后执行）、语音键生命周期（按下开始/松开结束、
不参与双击/长按延迟）、快速连按均与升级前一致。

**E8 · 边界**
按住期间断开遥控器 / 系统睡眠 / 退出应用 → 无粘键、无迟到连续拍；
闲置后首次按压（冷态）仍能正常起拍与连续。日志应出现
`map_repeat end … reason=reset|reconfigure|shutdown` 且之后无该键的 `map_repeat`/`map_fire`。

**E9 · 升级迁移**
用含本功能之前的版本写下配置（例如返回键 单击=「Delete」且按住会连续），升级后打开
按键页：该键显示**「重复单击动作」选中**、按住行为与升级前一致；组合键旧配置（如
单击=「Ctrl+C」）不再连续（**有意修正**，见 ATTRIBUTION 2026-10-05 记录）。

## 失败处置

| 现象 | 先看什么 |
| --- | --- |
| 按住完全不连续 | 该键是否有事件（返回/音量键需先开启「全按键支持」）；日志有无 `map_fire`/`map_inject` 逐拍记录；组里选中的是不是「重复单击动作」/「重复长按动作」 |
| 没开连续执行的按键也出现 `map_repeat` | 回归（不应发生）：只有连续触发计时器产生的拍才计入聚合，双击窗补发的单击与首次长按是一次性手势 |
| 连续一拍后就停 | `release` 边沿是否提前到达（粘键/迟滞）；日志 `map_repeat end` 的 reason 与 beats |
| 按一下出两次 | 该键是否走了泄漏对冲路径且动作与原生相同；对照 `map_skip_inject` 记录 |
| 选项置灰 | 按键是否在范围内、动作是否可连续执行、该键是否已配长按动作（悬停与常驻原因即说明） |
| 升级后行为与旧版不一致 | 打开 `button-mappings.json` 检查 `schemaVersion` 与 `holdRepeat`；组合键不再连续属有意修正 |
