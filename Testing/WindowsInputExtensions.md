# 输入扩展验收

本手册覆盖鼠标动作、应用库、遥控器缓存电量与 RC003 可选采集路径。步骤是验收方法，不代表所有场景均已通过。

## 自动化检查

```powershell
.\scripts\ci-preflight.ps1
cargo test --workspace --features runtime-simulation -- --test-threads=1
python -I -B Testing/rc003-user-hid/test_capture.py
python -I -B Testing/rc003-user-hid/test_bridge.py
node Testing/rc003-user-hid/test_hid_tap.cjs
node Testing/rc003-user-hid/test_gadget_adapter.cjs
```

Helper 的 34 项离线测试覆盖三键解析、认证、来源与数量限制、重复输入、租约和停止。测试使用模拟对象，不提权、不加载 Frida、不访问系统宿主。它们不验证反作弊兼容性，也未修复已知握手合包问题。

## 鼠标与应用库

- 验证左/右/中键单击及左键双击，点击不移动指针，按下与松开成对，部分提交时尝试释放。
- 验证上下滚轮每次 1–100 格及无效数值拒绝，格数不是网页像素；目标距离由 Windows 与应用设置决定。
- 验证四方向指针移动每次 1–2000 物理像素，覆盖 DPI 缩放、多显示器跨屏和边缘限制。
- 分别用 RC001、RC003 验证实体按键、闲置后首按、单击/双击/长按、连发、松开、禁用映射和退出清理。
- 验证应用库扫描、搜索、多选、全选、扫描失败重试，以及保存、导入、导出。扫描和添加不应自动启动或绑定应用。
- 核对用户已有设置保留，不为测试覆盖个人绑定；使用隔离测试配置执行修改类测试。

## 缓存电量

- 验证 0%、100% 和缺失/错误属性，未知值不能显示成 0%。
- 切换设备、断连、睡眠时拒绝迟到缓存，不显示另一设备的电量。
- 验证缓存查询不新增 GATT 会话，不影响语音；RC001 与 RC003 分别验收。

## RC003 增强采集

- 默认关闭，取消风险确认或 UAC 后不启动；断连重连后不自动开启。
- 三键首次完整按下/松开只确认，不执行动作；之后按所选动作测试，无重复或迟到执行。
- 验证按住时停止、断连、睡眠、宿主变化、心跳超时，立即撤销动作许可并请求清理。
- 单独验证普通键盘、媒体键和多蓝牙 HID 设备隔离，以及增强采集下的语音回归。
- `proxy_unverified` 不得显示为完整逐设备归因；清理确认不等于 DLL 已卸载。
- RC003 过滤信号通道仅接受选中设备的目标 VK，普通键盘不能解锁三键；不提供或安装内核驱动。

增强采集与游戏反作弊可能无法同时正常运行，兼容性尚未验证。这是软件共存问题，不是游戏作弊判定的结论。本手册不要求在游戏或反作弊环境下试验。真实采集测试应由知情测试者显式启动，不能把离线模拟当作硬件通过。

## 图标与打包

- 核对应用、托盘、安装器、卸载器、关于页及 favicon 的资源和许可。
- 构建输出需检查多尺寸图标与生产/仿真隔离，不以构建成功替代安装、启动和 Shell 缓存验收。
- 普通构建不附带 Helper；使用包含 Helper 的覆盖配置时，检查其对应源码、依赖和许可均被打包。

## 结果边界

鼠标桌面操作与 RC003 三键确认已有功能验证。完整实体按键、闲置首按、连发、语音、多设备、断连/睡眠、图标 Shell 缓存及游戏反作弊共存验收仍按未完成处理。使用 `passed`、`failed`、`deferred` 记录实际执行结果，不上传个人配置、原始语音或设备身份。
