# Windows 鼠标动作验收

本手册覆盖鼠标点击、滚轮和指针移动按键映射。步骤是验收方法，不代表所有场景均已通过。

## 自动化检查

```powershell
.\scripts\ci-preflight.ps1
```

## 桌面和真机验收

- 验证编辑区只有一个「鼠标动作」分组，顺序为点击（左键单击/右键单击/左键双击/中键单击）→ 鼠标向上/向下/向左/向右 → 滚轮向上/向下 → 数量输入框；输入框按当前选择显示「每次滚动」或「每次移动」及其当前值。四方向按钮显示文字，不显示箭头。默认宽度下点击按钮一行，四个方向与滚轮按钮合并为下一行。
- 验证「每次移动 … 像素」后显示「请输入 1 到 100 之间的整数，并按Enter或鼠标点击空白处保存配置。」；0、101、负数或非整数不保存，错误提示显示在同一输入框旁，页面底部不再出现该提示。
- 验证左/右/中键单击及左键双击，点击不移动指针，按下与松开成对，部分提交时补发释放。
- 验证上下滚轮每次可输入 1–100 的整数（默认 20，0/101/负数拒绝），输入框为普通文本框、无上下加减按钮；按 Enter 或失焦后立即保存并生效；格数不是网页像素。
- 验证四方向指针移动每次可输入 1–100 的整数（默认 20，0/101/负数拒绝），输入框为普通文本框、无上下加减按钮；按 Enter 或失焦后立即保存并生效；覆盖 DPI 缩放、多显示器跨屏和屏幕边缘。
- 分别用 RC001、RC003 验证实体按键、闲置后首按、单击/双击/长按、连发、松开、禁用映射和退出清理。
- 核对现有用户设置保留，不为测试覆盖个人绑定。

RC001/RC003 真机完整回归和多显示器跨屏验证仍为 `deferred`。
