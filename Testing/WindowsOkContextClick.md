# OK 键「移动光标后按 OK 点击」真机验收（RC001 / RC003）

> 状态：**待执行**（自动化已 passed；本手册全部用例需真实遥控器与安装包）。
> 适用：2026-10-06 起的本地测试包/安装版；**RC001 与 RC003 分别执行**。
> 功能口径见 `docs/plan/2026-10-06-ok-context-click.md` 与
> `docs/product/button-behavior.md` §2。

## 要验什么

OK 编辑页的按键级开关（默认关）。开启后：用遥控器移动过光标后的 **5 秒内**，
按 OK 在光标位置**立即左键单击一次**，且**本次按压的单击 / 双击 / 长按都不执行**；
窗口外或开关关闭时，OK 行为与原来完全一致。

## 前置条件

- RC001 或 RC003 已配对并连接；应用为包含本功能的构建。
- 有一个"能看见点击效果"的目标：记事本（光标放正文里、点击应落光标）或网页上的按钮。
- 方向键（或任一可映射键）已配「鼠标移动」，用于用遥控器移动光标。
- 可读取诊断日志（默认日志目录或 `SAYALL_GATT_LOG` 指定路径）。

## 用例

**E1 · 开关关闭（回归）**
配置：OK 单击=「Enter」，开关关闭。
判据：按 OK 与升级前一致（单击/双击/长按各自生效），不产生任何鼠标点击。
日志：无 `map_ok_click` 行。

**E2 · 命中窗口**
配置：方向键=「鼠标移动」，OK 开关打开、单击=「Enter」。
步骤与判据：用遥控器把光标移到网页按钮（或记事本正文某处）→ 5 秒内按 OK →
立即点击一次（按钮被按下/光标落点变化）；**不触发 Enter**（不会额外换行/提交）。
日志：`mouse_move phase=completed …` → `map_ok_click action=click elapsed_ms=<≤5000>` → `map_fire … action=mouse_click`。

**E3 · 窗口过期**
步骤与判据：移动光标后等 **>5 秒**再按 OK → 走原动作（Enter），不点击。
日志：`map_ok_click action=skip reason=window_expired elapsed_ms=<略大于 5000>`。

**E4 · 连点**
步骤与判据：窗口内快速按两次 OK → 两次点击（在支持双击的界面上形成双击），不触发原动作。

**E5 · 长按**
步骤与判据：窗口内按住 OK 不放 → 只在按下沿点击一次；不触发 OK 的长按动作；松开无动作。

**E6 · 生命周期**
步骤与判据：按住期间断开遥控器 / 系统睡眠 / 退出应用 → 恢复后第一次按 OK **不**点击
（除非又用遥控器移动过光标）；无迟到点击。
日志：重连后首次按 OK 无 `map_ok_click action=click`。

**E7 · 边界确认**
- 用电脑鼠标移动光标后按 OK：窗口不刷新也不清空（若 5 秒内遥控器移动过，仍会点击）；
- 点击会激活光标所在窗口；在桌面/文件夹空白处点击会取消选择（预期行为）；
- 无"点击 + 原生动作"双重效果（若该型号 OK 有原生事件，属既有泄漏边界，记录观察结果）。

## 失败处置

| 现象 | 先看什么 |
| --- | --- |
| 窗口内按 OK 不点击 | 日志 `map_ok_click`：`reason=window_expired`（超 5 秒）/ `reason=no_recent_move`（没移动过）/ `reason=gate_not_alive`（门控未就绪）/ `reason=inject_failed`（注入被拒） |
| 点击了但也执行了原动作 | 该型号 OK 是否有原生事件（既有泄漏边界）；对照 `map_fire` 与 `map_skip_inject` |
| 开关打开但完全不生效 | 确认保存后的配置里 `okContextClick=true`（开关是否真的开）；方向键确实注入了鼠标移动（`mouse_move phase=completed`） |
| 每次按 OK 都点击（不想点） | 关掉开关，或用电脑鼠标重新摆放光标前先等窗口过期 |
