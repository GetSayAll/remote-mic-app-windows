# RC001（小米蓝牙遥控器 2）三键映射回归验收

> 状态：**E1–E5 全部已执行并通过（2026-09-25，Andy 真机）**。
> 本手册只覆盖**基础按键路径**的回归（三键 + 既有按键约定）；RC003 的提权助手轨见
> `Testing/WindowsRC003EnhancedCapture.md`。

## 背景与本次要验的是什么

2026-09-24 做过两处会影响 RC001 的产品决策与代码改动：

1. **按键页不再区分型号**（`#f574abc`）：RC001 专属的能力说明（"以厂商键 VK 0xFF 到达…"）
   已删除，两个型号共用同一套随开关状态的文案；「增强捕获」开关也在 RC001 上显示。
2. **增强捕获的授权语义重做**（`#6ac7acf` / `#d813193` / `#42eaa65`）：开关状态以
   「设置里的意图」为准，UAC 取消/叉掉不再误开，重装/升级后需重新授权。

### ⚠️ 本手册初稿的前提写反了（2026-09-25 真机更正）

初稿按"RC001 三键以厂商键 VK 0xFF 到达、`key_gate` 直接归因、**不需要提权助手**"
写判据（E2 关闭开关也要能映射）。**真机推翻了这个推论**：Andy 实测 RC001 与
RC003 表现**完全一致**——

- **增强捕获开启 → 三键可映射**；
- **增强捕获关闭 → 三键不映射**。

也就是说：**两个型号的三键都依赖增强捕获**。产品口径与界面文案（"需先开启
『增强捕获』开关才会生效"，两个型号共用）与真机一致，无需再区分型号。
下面的 E2–E4 已按更正后的判据重写。（长期备忘里"RC001 免助手"那条也已更正。）

## 前置条件

- RC001 已与本机配对并在应用内连接成功（界面显示遥控器名；日志里出现 `rc001`）。
- 应用为包含上述提交的版本（≥ `42eaa65` 的本地包）。
- 记事本（或其它可输入文本的目标）已打开，作为映射效果的观察窗口。
- 语音键相关回归不在本手册范围（见既有语音验收文档）。

## E1 · 型号识别与界面文案

**操作**：连接 RC001 → 打开「按键映射」页 → 选中返回键。

**判据**

- 页面按 RC001 正常渲染（12 个按键卡 + 语音卡 + 36 个触发格）。
- 能力说明**不得**出现 RC001 专属旧文案（`VK 0xFF`、`厂商键`）。
- 开关关闭时，说明指向「需先开启『增强捕获』开关才会生效」；
  这是统一文案（对 RC001 而言偏保守，属已知的产品口径，非缺陷）。

**证据**：截图 + 诊断日志中型号字段为 `rc001`。

## E2 · 关闭增强捕获时三键不映射（阴性对照）

**操作**：保持增强捕获**关闭** → 返回 / 音量+ / 音量− 各配一个可观察的映射
（例如返回 → 键盘 `b`、音量+ → 键盘 `c`、音量− → 键盘 `d`）→ 焦点放回记事本 → 逐键按压。

**判据**：记事本**不出现**对应字符（且不应有该键的原生副作用）。
这一条是 E3 的阴性对照——没有它，"能映射"无法与"根本没配好"区分。

**证据**：诊断日志中出现对应的 `chord_press` / 映射动作记录。

## E3 · 开启增强捕获后三键可映射（关键项）

**操作**：打开「增强捕获」开关（首次需一次 UAC；本机任务已注册则直接拉起助手）
→ 等状态行变为「增强捕获已开启」→ 重复 E2 的三个键。

**判据（三条都要满足）**

1. 按下对应键，记事本出现预期字符；
2. 每个键**只触发一次**（不重复、不粘键）；
3. 不产生该键的原生副作用（例如返回键不会退回上一页）。
- 若同时连着其它 BLE 键鼠设备：那个键盘打字正常（agent 的内容门禁只认
  `0x00F1`/`0x0080`/`0x0081`，RC001 与其它设备都不发出这三个 usage）。
- 助手日志不应出现针对 RC001 按键的 `[EDGE]`（RC001 的按键不经过 HID 宿主报告层）。

**证据**：助手日志心跳正常（`handshake=true`、`lease_ok`）；诊断日志边沿记录只来自 RC003 三键（若 RC003 同时连接）。

## E4 · 关闭开关后回到不映射（与 RC003 一致）

**操作**：关闭「增强捕获」开关 → 等助手退出（≤ 2 秒）→ 重复 E2 的三个键。

**判据**

- 三键**不再映射**（回到 E2 的状态；两个型号行为一致）。
- 进程列表里不再有 `sayall-helper.exe`。

## E5 · 其它按键无回归 ✅（2026-09-25 真机通过）

**操作**：按既有约定验证下列按键仍按原行为工作：

- 确定 / 方向键：映射生效；
- 主页键：启用「遥控器优先」后，遥控器连接期间原生 Home 被接管，物理键盘对应键触发映射动作；
- 语音键：按住说话（按下开始、释放结束），不参与双击/长按延迟。

**判据**：与改动前一致；任何一项不一致即为回归，需先定位再继续。

## 失败处置

| 现象 | 先看什么 |
| --- | --- |
| 三键完全无反应 | 诊断日志里该键是否有事件（Raw Input / key_gate）；确认遥控器已连接且型号为 `rc001` |
| 触发两次 / 粘键 | 边沿配对日志（按下/释放是否成对） |
| 开关状态与预期不符 | 诊断日志 `feature=enhanced-capture` 与 `rc003_capture_toggle` 两处记录 |
| 助手起不来 | `hardware/RC003/helper` 下 `run-helper-selftest.cmd`（免提权）+ `%ProgramData%\SayAll\rc003-helper\helper-task.log` |
