# Windows 发布时限与重试边界

## 计时口径

- `request_started_at`：用户或发布任务开始时间；
- `T_ready`：代码已合入 main、CI/依赖检查通过、版本和说明冻结；
- 报告分别给出总耗时与 `T_ready` 之后的纯发布耗时。

## 重试规则

- 同一 SHA、版本、Build 和 artifact 身份上的基础设施/网络失败可以重试，不创建 rerun 分支、不升版本、不重签成功字节。
- Tag、Release 或资产建立后，内容差异必须回到普通 PR 并使用新版本；旧身份不可修改。
- 超时、权限、认证、5xx 或未知状态均按失败处理并保留现场。

SLO 只是发布观测指标，不能替代签名、摘要、安装器、Windows 真机或 RC001/RC003 验收。
