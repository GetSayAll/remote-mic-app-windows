# Windows 按键模板测试

本专项覆盖固定按键模板、应用关联、菜单手选、当前模板同步、编辑选择锁与输入工具读取。RC001 与 RC003 必须分别验收；自动化通过不代表遥控器、第三方应用或 Windows 实际行为通过。

## 当前契约

- 模板包含单击、双击和长按配置。语音键始终按下开始、释放结束，不参与双击或长按等待。
- 自动模式根据前台应用的已保存关联选择模板；没有匹配关联时使用通用配置。手动模式按用户选择使用模板，不由前台切换覆盖。
- 开启菜单切换时，菜单键用于选择模板；关闭时恢复其已配置行为。取消菜单不改变当前配置。菜单选项、按键页和模板页显示实际已应用的模板，不以正在编辑的草稿代替。
- 编辑选择锁默认锁定；按遥控器不会移动正在编辑的按键。解锁后允许跟随观测到的按键；锁状态保存后跨页面、重启保持。映射仍须显式保存，失败时保留草稿并提示。
- 读取输入工具失败时显示读取失败，不从共享快捷键推断工具并写回。只有用户明确选择后才保存；失败回退并读回实际状态。
- 共享模板导出不携带聚焦档案，导入预览/应用剥离来源文件中的档案，包括应用路径键、记录的输入框名称、自动化标识与窗口标题。普通本机保存与运行热更新继续保留档案；仅导入所选模板时保留未选本机模板与通用配置的档案。旧版共享文件只清除其导入的映射，不清除继承的现存模板。
