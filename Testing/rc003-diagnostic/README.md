# RC001 / RC003 按键诊断工具

本目录保留三键输入问题调查使用的独立 Windows 工具。文件名中的 RC003 是历史名称；连接目标以标准 Model Number 和实际设备为准，不能据文件名判断型号。
它不是修复后的 SayAll，也不安装驱动。

## 当前版本（v3）

每个目标键测试前后，要求按一次遥控器上键并松开。只有 Raw Input 和短期低级键盘钩子都收到完整 DOWN/UP 对照才继续。
目标键窗口分别为返回、音量加、音量减，每段 6 秒。保持工具前台，按界面提示操作，不要使用普通键盘干扰对照。
对照 15 秒未通过或窗口失去前台会停止；这种结果不能解释为硬件不支持。

2026-09-13 的 RC001 记录中，六个前后对照均通过，三个目标窗口未观察到 Raw/候选 LL 事件。
这是限定测试路径的阴性结果，不表示设备没有发送 HID 报文；由此转向可选下层过滤驱动。

## 构建与使用

需要 x64 Windows、自带 .NET Framework 4.x 和 Windows WinMetadata，不需要 Rust 或管理员权限。

```powershell
powershell -NoProfile -File .\Testing\rc003-diagnostic\Compile.ps1
.\Testing\rc003-diagnostic\RC003-Diagnostic.exe
```

1. 从 SayAll 托盘菜单正常退出，保持目标遥控器已配对且只连接一台。
2. 打开工具，确认识别的型号，按界面开始采集。
3. 跟随每段提示按键；对照失败时保留失败结果，不强行继续解释。
4. 等待清理完成。可用“停止并清理”中止。
5. 日志在程序旁 captures 目录。先检查隐私后再向开发者分享，不提交进 Git。

工具只观察、不吞键或注入；遥控器的系统原生效果仍可能发生。

## 范围及限制

- 原始设备身份只在内存中用于设备归因，不保存 MAC/HID 路径。
- Raw Input 只记录匹配小米 VID/PID 的事件；LL 没有设备身份，只记录有限候选虚拟键，并标记 unattributed。
- LL 候选集不包含三键驱动转换后的 F13–F15。安装驱动后的最终验收请使用新版 SayAll 的 three_button_driver/map_fire 日志与目标应用响应，不用本工具的 LL 阴性证明驱动失败。
- v1 曾检查 HID 描述符/可访问 GATT 通知；v2 增加 LL 观察，但首段 LL 对照缺失；v3 引入每段前后完整对照。
- 早期日志已确认标准型号是 RC001。上方向长按成功本身不能证明短按需要延时；短按、释放和前后台对照需要分开记录。

实际驱动、配置和回滚见 [完整指南](../../docs/three-button-driver-guide.md)。
