# 无线麦 SayAll Windows 版 v0.2.12 预览版

本次更新（相对上一个已发布版本 0.2.6）：

## 新增

- 遥控器按键现在可以绑定鼠标动作：左键、右键、中键单击，左键双击，每次 1–100 格的滚轮，以及每次 1–2000 物理像素的指针移动；滚轮格数与指针位移分别设置。
- 新增应用库：扫描并搜索本机已注册的应用，多选或全选后保存，可导入导出配置；扫描和添加本身不会启动应用，也不会改动已有按键绑定。
- 遥控器电量显示：读取 Windows 已缓存电量并在界面呈现，断连、睡眠或数值缺失时显示未知，不会额外建立蓝牙连接。
- 关于页新增「登录时自动启动」开关，默认关闭；开启后随 Windows 登录自动运行，不需要管理员权限。
- 关于页新增「打开日志目录」入口，诊断摘要的复制入口也一并移到该页，权限页只保留蓝牙、按键、音频三项状态。

## 改进

- 修复安装或升级时安装器强制结束应用的问题。此前若应用正连着遥控器，强制结束会让系统蓝牙栈失去响应，且只能通过重启电脑恢复；现在安装器会先请求应用正常退出，应用自行结束蓝牙会话后才继续安装。
- 蓝牙栈已经失去响应时不再反复尝试开关蓝牙无线电，改为直接重连，避免无效操作打断链路；其他失败原因仍然保留原有恢复手段。
- 蓝牙重连与无线电恢复改为持续自愈：部分建立失败的连接会被完整释放，不再累积占用。
- 遥控器语音键在重连期间不再泄漏成普通 F5 按键。
- 遥控器连接后，若系统缺少可用的按键接口，按键监听改为常驻等待并自动恢复，不再需要手动重启应用。
- SayAll 自身处于前台时不再重复激活输入法，避免语音会话触发界面重新加载。
- 菜单键唤回窗口后，点击关闭按钮可以正常隐藏到托盘，不再失效。
- 鼠标指针移动在缩放屏幕上使用正确的 DPI 上下文，修复 150% 缩放下位移偏大的问题。
- 开机自启动开关会校验登录启动项指向的可执行文件路径，路径不符时不再显示为已开启。
- 按键门控只在已绑定唯一遥控器设备时启用归因，避免误吞其他键盘设备的按键。
- 修复三处界面问题：打开应用列表的悬浮内容被裁切、自启动开关滑块错位、以及非 Tab 导航下出现的焦点环。
- 隐私安全诊断日志新增资源占用采样与失败原因保留，失败时不再只记录分类结果。

## 验证

- `scripts/ci-preflight.ps1`：passed
- 相关改动的 Windows CI（含前端测试、Rust 工作区测试、NSIS 构建、升级/降级保护、卸载与静默安装矩阵）：passed
- 安装器优雅退出契约测试已接入 CI，覆盖「应用正在运行时执行安装/卸载」这一此前无覆盖的场景
- 开机自启动真机验证：passed（注销重登后自动启动，进程由登录 shell 拉起）
- 鼠标动作、应用库、电量显示的 RC001/RC003 真机回归：deferred
- 蓝牙栈失去响应场景的真机复验：deferred（需要完整重启后才能构造干净的初始状态）

## 已知边界

- 应用内更新通道不可用，本包仅供手动安装验证。
- 安装器尚未配置 Windows Authenticode 代码签名，首次运行可能出现 SmartScreen 提示。
- 从 0.2.12 之前的版本升级时，因旧版没有优雅退出监听，安装器会中止并提示先手动退出应用；手动退出后重新运行安装程序即可。这是为避免强制结束造成蓝牙栈失去响应而刻意保留的行为。
