# 无线麦 SayAll Windows 版：安装与配置

本文适合第一次安装的普通用户，也适合协助用户安装的 AI Agent。请按顺序完成；不要跳过“完成标准”。

## 1. 准备清单

- 64 位 Windows 10 1809（内部版本 17763）或更高版本；
- 可用的蓝牙适配器，并已在 Windows 中打开蓝牙；
- 可用的网络连接：安装器会在系统缺少 WebView2 Runtime 时在线下载安装，应用更新和微信输入法语音识别也需要联网；
- 小米蓝牙遥控器 2（RC001）或小米蓝牙遥控器 2 Pro（RC003），以及电量充足的电池；
- 如需把遥控器语音交给输入法或会议软件：安装 VB-CABLE 需要管理员权限，并需要重启一次 Windows；
- SayAll 主程序本身按“当前用户”安装和运行，不需要、也不应以管理员身份日常运行。

> SayAll 只支持 RC001 和 RC003。外观相近不代表协议兼容，请以应用连接后显示的型号为准。

## 2. 下载并安装 SayAll

1. 打开仓库的 [GitHub Releases](https://github.com/GetSayAll/remote-mic-app-windows/releases)，选择标记为“Pre-release”的目标预览版；稳定版上线后，也可选择标记为“Latest”的版本。
2. 下载 `SayAll-Windows-<版本号>-x64-setup.exe`。不要下载 `latest.json` 或 `.sig` 文件来手动安装。
3. 建议同时下载 `SHA256SUMS.txt`，在安装包所在目录打开 PowerShell，执行：

   ```powershell
   Get-FileHash -Algorithm SHA256 .\SayAll-Windows-*-x64-setup.exe
   Get-Content .\SHA256SUMS.txt
   ```

   两处安装包哈希值应完全相同。若不同，删除安装包并停止安装。
4. 双击安装包，选择语言并按提示完成安装。安装位置由安装器管理，不需要手动选择。
5. 从开始菜单的“无线麦 SayAll”文件夹启动“无线麦 SayAll”。

### Windows 安全提示

首版安装包可能还没有 Authenticode 代码签名，因此 Windows SmartScreen 可能显示“Windows 已保护你的电脑”。只有在安装包来自上述官方 Release、文件名正确且 SHA-256 校验一致时，才可选择“更多信息”并继续运行；来源或校验不明时不要绕过提示。

## 3. 在 Windows 中配对遥控器

SayAll 只能扫描已经由 Windows 配对的遥控器。Windows 的“已配对”和 SayAll 的“已就绪”是两个不同状态。

1. 打开“设置 → 蓝牙和设备”，打开蓝牙，再选择“添加设备 → 蓝牙”。Windows 10 中对应入口是“设置 → 设备 → 蓝牙和其他设备”。微软的通用步骤见[在 Windows 中配对蓝牙设备](https://support.microsoft.com/en-US/Windows/Hardware/bluetooth/pair-a-bluetooth-device-in-windows)。
2. 把遥控器放在电脑附近，同时长按“菜单”和“主页（HOME）”键，直到它进入配对模式并出现在 Windows 的设备列表中。
3. 选择名称类似“小米蓝牙语音遥控器”的设备，等待 Windows 显示配对完成。

“菜单 + 主页”组合已在 RC003 上验证；不同批次 RC001 若没有进入配对模式，请以随附说明书为准，不要反复快速按键。遥控器若仍与电视或盒子连接，可暂时关闭原设备的蓝牙，避免它抢先连接。

## 4. 安装 VB-CABLE（使用语音时必需）

SayAll 把遥控器声音写入播放端 `CABLE Input`，输入法或会议软件再从录音端 `CABLE Output` 读取。两个名称看似相反，这是 VB-CABLE 的正常信号方向。

1. 在 SayAll 中打开“连接与语音”。如果页面提示缺少 VB-CABLE，选择“打开官方下载页”；也可以直接打开 [VB-CABLE 官方页面](https://vb-audio.com/Cable/)。
2. 下载 VB-CABLE 压缩包，并把全部文件解压到本地文件夹。不要直接在压缩包内运行安装程序。
3. 64 位 Windows 用户右键 `VBCABLE_Setup_x64.exe`，选择“以管理员身份运行”，然后选择“Install Driver”。
4. 安装完成后重启 Windows。VB-Audio 的[官方参考手册](https://vb-audio.com/Cable/VBCABLE_ReferenceManual.pdf)也要求安装后重启。
5. 重新打开 SayAll 的“连接与语音”，选择“刷新设备列表”。如果系统中只有一个 VB-CABLE，SayAll 首次启动时会自动选择它；否则手动选择 `CABLE Input`。

完成标准：语音设备卡片显示 `CABLE Input`，状态为“已就绪”。

## 5. 在 SayAll 中连接遥控器

1. 打开“连接与语音”，选择“扫描已配对设备”。
2. 在目标遥控器旁选择“连接”。
3. 等待状态变为“已就绪”，并确认页面显示 RC001 或 RC003。

SayAll 会记住用户选择的遥控器和语音设备，之后启动、临时断连以及睡眠唤醒时会自动恢复。关闭主窗口只会把应用隐藏到系统托盘；需要完全退出时，使用托盘图标菜单中的“退出”。

完成标准：

- 遥控器连接状态为“已就绪”；
- “语音按键”显示“已就绪”；
- “语音设备”显示 `CABLE Input` 且状态为“已就绪”；
- “按键映射”页底部显示“按键监听已就绪”。

## 6. 配置语音输入软件

### 微信输入法（默认配置）

1. 保持 SayAll 的“按住说话快捷键”为“微信输入法（默认）”，即左 Ctrl + 左 Win。
2. 在微信输入法的语音设置中把麦克风选为 `CABLE Output`。若软件不提供单独的麦克风选择，把 Windows 默认录音设备设为 `CABLE Output`。
3. 在目标应用中点入文本框，并切换到微信输入法。
4. 按住遥控器语音键约半秒后说话，松开后等待文字出现。微信输入法语音识别需要网络。

完成标准：按下遥控器语音键后输入法开始收音，松开后停止，并在当前文本框出现刚才说出的文字。

### 其他软件（Windows 听写、其他输入法等）

- SayAll 的“语音设备”仍选择 `CABLE Input`；所用软件（或系统默认录音设备）的麦克风选择 `CABLE Output`。Windows 听写使用系统默认录音设备；
- 在 SayAll 的“按住说话快捷键”中选择与该软件一致的快捷键：Windows 听写可直接选“Windows 听写（Win + H）”预设；其他软件选“自定义录入…”后按下目标快捷键，支持任意修饰键组合（含安全录入模式：界面选修饰键、键盘只按主键）；
- 若不需要 SayAll 注入快捷键，选择“关闭”，此时语音键仍会向 `CABLE Input` 输出声音；
- 某些软件会拒绝 Windows 模拟按键。出现这种情况时，语音音频仍可工作，但软件自己的按住说话快捷键可能无法由 SayAll 触发。

## 7. 配置普通按键（可选）

1. 打开“按键映射”，选择遥控器上的按键卡片。
2. 分别配置单击、双击或长按动作，可选预设快捷键、打开应用或录入自定义快捷键。
3. 设置会立即保存并生效；无需重启应用。

注意：配置双击后，单击需要等待约 0.3 秒来区分双击；长按约 0.55 秒触发。语音键不参与普通按键映射。页面中被禁用的按键是当前 Windows 输入路径的已知边界，不要通过直接编辑配置文件强行开启。

页面底部可显式保存当前配置，或将按键映射导出为 `.json` 文件后在另一台 Windows 电脑导入。导入会覆盖当前按键映射并立即生效；建议覆盖前先导出备份。Windows 与 macOS 的动作能力和配置契约不同，两端配置文件不能互相导入。

## 8. 更新、卸载与本地数据

- 更新：打开“关于 → 软件更新 → 检查更新”。发现新版本后选择“下载并安装”；应用会正常释放遥控器连接，安装完成后自动重启。
- 卸载：打开 Windows“设置 → 应用 → 已安装的应用”，找到“无线麦 SayAll”并选择“卸载”。
- 用户配置：卸载程序会保留 `%APPDATA%\app.getsayall.remote-mic.windows` 中的设置、映射和本机统计，便于以后重装恢复。
- 完全清除：先从托盘退出 SayAll，再由用户明确决定是否删除上述目录。该操作不可由 AI Agent 擅自执行。

## 9. 故障排查

### SayAll 扫描不到遥控器

先确认 Windows 蓝牙设置中已经存在该设备，再唤醒遥控器并回到 SayAll 重试扫描。不要把 Windows“已配对”误当成 SayAll“已就绪”。如果应用显示正在重连，请先给自动恢复最多约 60 秒；不要把重启电脑、重启蓝牙或重新配对当作常规步骤。

### 已连接，但语音软件没有声音

依次核对信号方向：SayAll 选择的是 `CABLE Input`，语音软件选择的是 `CABLE Output`。若刚安装 VB-CABLE 但设备列表中没有这两个端点，完成安装程序要求的 Windows 重启，然后在 SayAll 中刷新设备列表。

### 按住语音键没有触发输入法

确认当前文本框正在使用目标输入法、SayAll 中的快捷键（预设或“自定义录入…”结果）与输入法设置一致，并先测试输入法能否用物理键盘上的相同快捷键启动。快速点按不出文字通常是输入法自己的最短按住要求。

### 仍然无法解决

打开 SayAll 的“权限 → 诊断摘要 → 生成摘要”，先在页面内检查内容，再选择“复制摘要”并随问题描述一起提交。摘要不含设备地址、HID 路径、语音内容、音频设备身份或错误原文。

## 10. AI Agent 执行协议

AI Agent 协助安装时必须遵守以下边界：

1. 先确认系统版本、x64 架构、蓝牙可用性、安装包来源和 SHA-256；任何一项不满足即停止并向用户说明。
2. SayAll 安装器以普通用户权限运行。只有 VB-CABLE 驱动安装步骤允许请求用户确认 UAC；不得以管理员身份日常启动 SayAll。
3. SmartScreen、UAC、蓝牙配对和重启 Windows 都属于用户可见操作。Agent 必须解释原因并等待用户操作，不得尝试关闭安全机制或自动绕过提示。
4. 优先通过 SayAll 可见界面配置。不得修改第三方应用私有配置、内部数据库或进程内存，也不得用脚本直接编辑 SayAll JSON 设置来替代界面操作。
5. 不读取、记录或回传真实蓝牙地址、HID 路径、语音内容和个人路径。排障只使用应用生成的脱敏诊断摘要。
6. 连接异常时先观察应用自动恢复；除非应用明确提示公开 API 已无法恢复，否则不得把重启蓝牙、重新配对或重启电脑作为常规修复。
7. 每一步都按本文“完成标准”验证。看到进程存在、API 返回成功或 Windows 显示已配对，都不能替代应用内“已就绪”和一次真实语音上屏测试。

Agent 最终应向用户报告：SayAll 版本、遥控器型号（RC001/RC003）、四项应用内就绪状态、实际语音上屏结果，以及任何 `deferred` 项；不得把未执行的检查描述为 `passed`。
