# 鼠标映射与 RC003 增强采集

本版本提供鼠标动作映射、Windows 应用库和可选的 RC003 增强采集，同时包含遥控器电量显示及应用图标资源。本文说明功能、设置方法和验证边界。

## 游戏兼容性提示

**RC003 增强采集可能无法与游戏反作弊同时正常运行，相关兼容性尚未验证。使用 PC 玩竞技类游戏的用户请注意。这里说明的是软件能否同时运行，不是说使用它会被游戏判定为作弊；目前也没有这样的实测结论。**

| 功能 | 实现与风险边界 |
| --- | --- |
| 普通鼠标映射 | 点击、滚轮通过 Windows `SendInput`，指针移动通过 Windows 光标 API。该动作执行层不需要 Frida，已有桌面功能验证记录，不属于增强采集的进程注入路径。 |
| RC003 增强采集 | 独立管理员 Helper 向 Windows 蓝牙 HID 宿主 `WUDFHost.exe` 加载 Frida Gadget，属于进程注入。目标不是游戏进程；该组件可能无法与游戏反作弊同时正常运行，兼容性尚未验证。 |

增强采集默认关闭，启用前需要明确风险确认和 UAC 授权。停止采集会请求撤除钩子，但 Gadget DLL 及文件监视器可能继续驻留，直到 Windows 回收宿主。关闭主窗口只是隐藏到托盘，退出 SayAll 也不等于 DLL 已卸载。这是增强采集的清理边界，不是已发生游戏冲突的证据。

若遇到同时运行受阻的提示，应停止使用增强采集并反馈，不通过关闭或绕过反作弊来使用它。

## 鼠标绑定与数值设置

在按键页选择一个可配置的遥控器按键及其单击、双击或长按栏位，再选择鼠标动作。保存后沿用现有映射配置与手势处理，不自动覆盖原有绑定；语音键不增加普通鼠标手势。

| 动作 | 可配置项 | 实际含义 |
| --- | --- | --- |
| 鼠标点击 | 左键、右键、中键单击，左键双击 | 点击当前光标位置，不自动寻找目标控件。 |
| 滚轮向上 / 向下 | 每次 1–100 格，默认 1 格 | 每格对应 120 个 Windows 滚轮 delta 单位；不是网页滚动像素，实际距离由目标应用与 Windows 设置决定。 |
| 指针向上 / 下 / 左 / 右移动 | 每次 1–2000 物理像素，默认 30 像素 | 配置的是鼠标指针位移，不是滚轮距离；移动期间切换并恢复线程 DPI 上下文，屏幕边缘会限制位移。 |

滚动格数和移动像素均填写范围内的整数，保存后生效。按住连发会重复执行所选动作，表中的“每次”指一次动作，而不是整个长按过程。

## Windows 应用库

支持扫描 Windows 已注册应用、搜索、多选或全选添加，随后可将应用绑定为打开应用动作。扫描与添加本身不分配按键，也不批量启动应用；应用库随映射保存、导入和导出。

## 增强采集与普通动作的关系

RC003 增强采集只是返回、音量加、音量减三键的可选输入来源，确认后交给现有映射引擎，才可能执行鼠标、滚轮、快捷键或打开应用动作。如果使用该来源触发鼠标动作，增强组件仍然处于启用状态；改成鼠标动作并不会消除输入来源的兼容性风险。不能为了获得普通鼠标动作而默认开启 Helper。当前基础语音路径不依赖 Helper。

增强采集来源显示为 `proxy_unverified` 时，表示尚未确认完整逐设备归因。三键按下、松开确认成功不等于绑定动作、闲置首按、长按释放、睡眠恢复或语音回归均已通过。

详见[增强采集实现方案](architecture/rc003-enhanced-capture.md)，尤其是停止后驻留、安全边界和已知握手合包缺陷。

## 验证范围与已知问题

- 鼠标点击、滚轮、指针移动及应用库已有桌面功能验证；不将这些结果推广为所有应用或游戏均兼容。
- RC001 / RC003 的完整实体按键、闲置首按、连发与语音回归尚待完成；多显示器跨屏及边缘行为也需进一步验证。
- 增强采集的三键确认已验证；配置后的实际动作、增强下语音、断连及睡眠恢复尚未完整验收。
- Helper 存在握手合包问题：同批收到 `accepted` 与 `lease` 可能触发 `app_handshake_invalid`。该问题尚未修复。
- **增强采集与游戏反作弊同时运行的兼容性尚未验证。**

以下模拟测试共 34 项通过。测试不提权、不加载 Frida、不附加系统宿主、不发送真实按键，也不启动游戏或反作弊。

| 命令 | 结果 |

这组测试验证报文解析、去重、认证、租约和清理等模拟逻辑，不验证真实蓝牙采集、反作弊兼容性或已知握手合包缺陷的修复。若需真实采集测试，可在不安装游戏反作弊的独立 Windows 测试机上进行知情、显式开启的硬件测试，但这种结果仍不能代替具体反作弊产品的兼容性确认。
