# Windows 应用打磨计划（2026-09-05）

前置：此前全部修改已随 PR #19 合入 main（含按键映射、Mac 对齐 UI、

## 原则（用户明确要求）

1. **文案修改只改文案**：不改功能、IPC、数据结构、业务逻辑。
2. **改前先查测试**：建立测试基线；界面文案变化需同步测试断言
   （实测依赖：`runtime-simulation.ts` 引用「更换端点」「扫描已配对设备」
   与四个导航标签；vitest 18 项不依赖中文文案）。
3. **每完成一项 → 充分检查（vue-tsc / vitest / 浏览器实测）→ 再下一项**。
4. 核心准则：页面上不出现普通用户看不懂、没必要知道的信息
   （术语、技术词汇、硬件编码、协议名、采样率等）。

## 任务清单

### T1 窗口尺寸：当前运行尺寸为默认值与最小值
- 实测：当前窗口客户区 **1029×732**（物理=逻辑，DPI 100%）。
- 改：`tauri.conf.json` width/height=1029/732，minWidth/minHeight 同值。
- 验证：重启应用实测窗口尺寸；`verify-windows-bundle.ps1` 通过。

### T2 所有页面不显示右侧滚动条 + 移除每页副标题
- `.content` 隐藏滚动条（`::-webkit-scrollbar{display:none}`，仍可滚动）；
  配合 T7 减少内容量。
- 移除四页标题下的灰色说明段（按键/连接/权限/关于）。
- 验证：浏览器实测四页无滚动条、无副标题；仿真断言同步（如有引用）。

### T3 遥控器照片清晰度
- 事实：`public/RC003-remote-photo.png` 与 Mac 端**字节相同**（1024×1536，
  2.3MB），源不低清；模糊来自浏览器 5 倍缩小重采样。
- 改：预生成 2× 显示尺寸（404×820，HighQualityBicubic）资产替换引用，
  保留原图路径不变（避免缓存/打包问题则新文件名）。
- 验证：真机截图对比清晰度（边缘/文字锐度）。

### T4 不可自定义按键禁用（含悬停说明）
- 范围：`back`、`volume_up`、`volume_down`（调查归档：三键事件不进
  Windows 输入栈，映射无法生效）。
- 改：三键卡片格子置灰不可点（**不移除卡片**），卡片/格子悬停说明
  「此按键在 Windows 上暂不支持自定义」；已有配置保留显示。
- 不改引擎/数据（纯 UI 禁用；三键本就无事件）。
- 验证：vitest + 浏览器实测（置灰态、悬停提示、其他键不受影响）。

### T5 开关悬停说明（参考 Mac .help()）
- 参照 Mac 文案（zh-Hans.lproj）：
  - 锁定当前按键 →「开启后，操作实体遥控器不会切换正在编辑的按键。」
  - 连发开关（Windows 暂无此开关，跳过）
  - 新增：启用自定义按键功能、按住说话快捷键预设、不可自定义键说明。
- 验证：浏览器悬停实测文案出现。

### T6 全页面白话文检查（只改文案）
- 重点清单（连接页最严重）：ATVV / 16 kHz、WASAPI 端点、会话代次、
  BLE 会话已就绪、睡眠恢复通知、16 kHz·帧120字节·已解码N个采样、
  虚拟麦克风候选端点、CABLE Input、已吞/泄漏/触发、当前环境不可用、
  RC001/RC003 编码、VID/PID、WinRT GATT 等。
- 方法：逐页 DOM 文本全量导出 → 逐条改写（普通用户视角：做什么、
  需要用户做什么）→ 同步 `runtime-simulation.ts` 断言 → 全量测试。
- 诊断类信息（已吞/泄漏/触发）不删除功能的可观测性，改为日志侧
  保留，页面不展示。

### T7 真实 logo
- 事实：`src-tauri/icons/icon-source.png` 与 Mac `AppIcon.png` **MD5 相同**
  ——窗口/任务栏/安装器图标已是真实 logo。
- 改：关于页的 logo 位（现为渐变色块+字符）改用真实 logo 图片。
- 验证：关于页截图。

### T8 托盘图标 + 关窗驻留
- `tauri` 启用 `tray-icon` feature；托盘菜单：显示主界面 / 退出。
- 用户点窗口 ✕ → 隐藏到托盘（不退出）；托盘「退出」才真正退出
  （语音会话/注入/吞键钩子正常清理）。
- 图标：现有真实 logo 32px 派生。
- 验证：真机关 ✕ → 托盘在 → 双击/菜单恢复窗口 → 托盘退出进程干净
  （无残留钩子/无 leaked_down）。

### T9 淡紫色页面答疑（待用户确认是否改）
- 结论：**不是 Windows 效果**。来源是应用自己的主题：
  `--accent: #5f62db`（紫蓝强调色）+ `body` 背景右上角
  `radial-gradient(rgba(111,115,238,0.12))` 紫色晕染 + 各处
  `rgba(95,98,219)` 紫调（选中/卡片/图标）。
- 可选改法（对齐 Mac 中性风格）：中性灰背景 + 系统蓝强调色。
- **本项不改代码，等用户拍板。**
