# OK 键「移动光标后按 OK 点击」方案（按键级开关）

- 日期：2026-10-06
- 需求人：Andy（2026-10-06 提出，同日定下三个决定）
- 状态：**已实现（自动化 passed）**，真机验收待执行（见 `Testing/WindowsOkContextClick.md`）
- 前提说明：**不查 Mac 原版参考**——Mac 侧没有此功能（Andy 明确）；本功能是 Windows 侧的上下文增强
- 关联：沿用现有鼠标动作（`MouseClick`/`MouseMove` 注入，见 `send_input.rs`）与按键编辑页
- 产品逻辑整理见 `docs/product/button-behavior.md`（面向学习参考，不含平台细节）

## 1. 需求与语义

用户用遥控器把光标移到某个位置后，希望按 OK 就是"点一下"（点网页按钮、播放器控件等），
而不是执行 OK 原来的映射。

开关开启后：

- **判定**：距「上一次由遥控器注入成功的鼠标移动」≤ **5 秒**（每次移动刷新窗口）；
- **命中窗口时按 OK**：在**按下沿立即**于光标当前位置注入一次左键单击；
  **本次按压的单击 / 双击 / 长按全部不执行**（松开无动作，不进长按计时）；
- **未命中窗口（或开关关闭）**：OK 行为与现在完全一致。

连续两次 OK = 两次点击（是否构成系统双击由 Windows 判定，不额外处理）。

## 2. 三个决定（Andy 2026-10-06）

| 项 | 决定 |
| --- | --- |
| 触发窗口 | **5 秒**，每次遥控器鼠标移动续期 |
| 窗口内 OK | **按下沿立即点击**；本次按压不触发原单击/双击/长按 |
| 开关与默认 | **OK 编辑页的按键级开关，默认关** |

## 3. 边界与失败路径

| 情形 | 行为 | 备注 |
| --- | --- | --- |
| 窗口过期后再按 OK | 走原动作 | 说明句写明 5 秒；日志记 `action=skip reason=window_expired elapsed_ms=…`，避免"点击没生效"无从查 |
| 窗口内长按 OK | 只在按下沿点击一次 | 不进长按计时、松开无动作 |
| 窗口内快速按两次 | 两次独立点击 | 由系统决定是否双击 |
| 开关开但 OK 没配任何动作 | 窗口外按 OK 无动作 | 与现状一致 |
| 断连 / 睡眠 / 退出 | 窗口清零 | 重连后第一次 OK 不点击（除非又移动过）；成对清理 |
| 遥控器移动注入失败 | 不刷新窗口 | 只在 `mouse_move` 注入**成功返回**时刷新（失败有既有日志） |
| 用户在窗口内用真实鼠标移动了光标 | 窗口不刷新也不清空 → 按 OK 仍点击（新位置） | 简化取舍：不监听真实鼠标输入（可选增强，见 §7） |
| 点击的副作用 | 会激活光标所在窗口；在桌面/资源管理器空白处点会取消选择 | "点哪算哪"的固有行为，不是缺陷 |
| 物理按键原生泄漏（若该型号 OK 有原生事件） | 本功能不吞它 | 真机验收确认无"点击 + 原生动作"双重效果（既有泄漏边界见 `Testing/WindowsButtonGestureRepeat.md`） |
| 识别器里的挂起状态 | 吞掉按压时同步清空该键状态 | 否则可能出现陈旧单击/双击尾随（实现必须覆盖，测试钉住） |

**明确不检测"光标下是否可点击元素"**：直接点击即可——点不到可交互元素时通常没有后果；
检测需要 UIA 命中测试（跨进程、几十毫秒、第三方应用可能卡住），收益不成立。

  （wire `okContextClick`，`#[serde(default)]`，false 不写盘）。
  **无需升 schema**：旧文件照常加载；旧版本读到未知字段会忽略（全仓无 `deny_unknown_fields`，
  均为忽略未知字段的默认行为）。
- `crates/sayall-windows/src/button_mapping.rs`：引擎维护 `last_remote_move_at`（`mouse_move`
  注入返回 `Ok` 时刷新）与 `OK_CONTEXT_WINDOW = 5s`；`handle_edges` 在 OK 按下沿判定命中 →
  注入左键单击、吞掉本次按压、记结构化日志（命中与跳过都记，便于一次日志拉取定位）。

- 前端：`src/lib/bridge.ts` + `src/pages/ButtonsPage.vue`（OK 键、单击/长按页底部显示、恒可用；
  双击页不显示，与「按住时连续执行」一致）+ 测试；文案按 §4。

## 6. 验收（真机，RC001 与 RC003 分别执行）

| 用例 | 步骤与判据 |
| --- | --- |
| E1 回归 | 开关关：OK 的单击/双击/长按与升级前一致 |
| E2 命中 | 遥控器移动光标到按钮上 → 5 秒内按 OK → 立即点击一次，原动作不执行 |
| E3 过期 | 移动后等 >5 秒按 OK → 走原动作；日志 `reason=window_expired` |
| E4 连点 | 窗口内按两次 → 两次点击（双击场景形成双击） |
| E5 长按 | 窗口内按住 OK → 只点击一次，不触发长按动作 |
| E6 生命周期 | 按住期间断连 / 睡眠 / 退出 → 恢复后第一次 OK 不点击（除非又移动过） |
| E7 边界 | 真实鼠标移动不刷新窗口（行为符合 §3 表格），无异常 |

证据：型号、时间、界面行为、日志行（`mouse_move`、`ok_context_click`、`mouse_click`）。

## 7. 明确不做（本轮）

- 不做"可点击元素"检测（§3 理由）；
- 不做右键 / 中键 / 双击的上下文点击（只左键单击）；
- 不监听真实鼠标移动（可选增强：用户动真鼠标后清空窗口）；
- 不做显式"鼠标模式"（按 TV 键切换、方向键移动 + OK 点击）——列为后续可选方案；
- 只对 OK 键提供（其他键不显示该开关）。
