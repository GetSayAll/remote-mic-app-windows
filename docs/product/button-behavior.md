# 按键行为产品逻辑：按住连续执行 与 移动光标后点击

> 本文描述**产品逻辑**——用户可见的规则、状态、边界与文案，不含任何平台实现细节。
> 供后续学习与对齐使用；两个功能的决策与验收见
> `docs/plan/2026-10-05-button-hold-repeat-radio.md` 与 `docs/plan/2026-10-06-ok-context-click.md`。
> 文案以 `docs/product-copy.md` 的规范为准。

## 0. 背景：一个按键的三个槽位

- 每个按键可分别配置**单击 / 双击 / 长按**三个动作；后文两个功能都**不涉及双击**。
- 时序（用户可见规则）：单击默认在按下瞬间执行；配置双击后，单击要等约 **0.3 秒**的
  双击判定窗；长按在约 **0.55 秒**触发。
- 动作类型有：单个按键、组合快捷键、打开应用、滚动、鼠标点击、鼠标移动等。
  其中**只有"单个按键（非修饰键）、滚动、鼠标移动"能连续执行**——后文"可连续执行"
  即指这一组；其余动作（组合快捷键、打开应用等）只执行一次。

## 1. 按住时连续执行

### 1.1 目的

把方向键 / 返回键 / 音量键当作"能一直按住的键"用：按住不放，动作自动重复，直到松手
（类似键盘按键的自动重复）。

### 1.2 状态与行为（单选三态）

| 选项 | 按住时的行为 |
| --- | --- |
| **关闭**（默认） | 按住只执行一次 |
| **重复单击动作** | 单击动作先执行一次，随后持续重复；配置了双击时，按住超过双击判定窗即按单击处理并开始重复（快速点按仍判双击） |
| **重复长按动作** | 长按动作在长按阈值处执行一次，随后持续重复 |

- 任何时候松开立即停止；不会出现"松手后还在重复"。
- 重复节奏由按键决定（返回键更快、方向/音量稍慢），用户不可调。
- 单选三态对同一个按键只有一个状态；单击页与长按页看到的是同一个状态。

### 1.3 可用性规则

- **按键范围**：方向键、返回键、音量+、音量−。其他按键不显示该设置。
- **动作范围**：只有"可连续执行"的动作可选；其余动作不可选。
- **并存规则**：按键已配置长按动作时，"重复单击动作"不可选——按住会先执行长按，
  重复单击按不出来。此时的原因句会指向"重复长按动作"。
- **不可选项必须给出原因与恢复方式**（不允许只置灰不解释），且**不得指向同样不可选的选项**：
  若长按动作本身"只执行一次"，则单击选项的原因改为"要连续执行单击动作，请先清除长按动作"。
- 说明句只陈述本页事实，不承诺被置灰的功能；各选项的行为说明放在该选项的悬停提示里。

### 1.4 配置变化时的收口

- 已选目标因配置变化不再可用（例如为按键新配置了长按动作、或目标动作被改成"只执行一次"）
  → 自动回到"关闭"并给出提示；**不偷偷改选到另一个目标**。
- 提示与原因句同规则：一句话讲清事实（+ 可行时的下一步），不指向不可用的选项。

### 1.5 边界与已知取舍

- **双击语义保持现状**：先点一下、紧接着第二下按住不放，在"关闭"状态下松手仍按双击处理。
- 同一次按压里不会既触发单击又触发长按。
- 该功能只改变"按住"的重复行为，不改变单击/双击/长按各自的触发条件。

### 1.6 文案清单（唯一实现依据）

| 位置 | 文案 |
| --- | --- |
| 设置名 | 按住时连续执行 |
| 选项 | 关闭 / 重复单击动作 / 重复长按动作 |
| 悬停·关闭 | 按住不放只执行一次 |
| 悬停·重复单击动作（未配双击） | 按住不放，单击动作会不断重复，直到松手 |
| 悬停·重复单击动作（已配双击） | 按住超过约 0.3 秒开始，单击动作会不断重复，直到松手 |
| 悬停·重复长按动作 | 按住约 0.55 秒后，长按动作会不断重复，直到松手 |
| 不可选·未配置对应动作 | 先给这个按键配置单击动作 / 先给这个按键配置长按动作 |
| 不可选·动作只执行一次 | “单击”/“长按”的动作只执行一次（组合快捷键、打开应用等），不能连续执行；把它改成单个按键后可选 |
| 不可选·已配长按（长按可连续） | 这个按键已有长按动作，按住会先执行长按；要连续执行，请选“重复长按动作” |
| 不可选·已配长按（长按只执行一次） | 这个按键已有长按动作：按住会执行长按。要连续执行单击动作，请先清除长按动作 |
| 状态条·选关闭 | 已关闭“按住时连续执行” |
| 状态条·选重复单击动作 | 已开启：按住不放会连续执行 |
| 状态条·选重复长按动作 | 已开启：长按后不松手会继续连续执行 |
| 状态条·自动关闭（新配了长按，长按可连续） | 这个按键已配置长按动作：按住会先执行长按，“按住时连续执行”已关闭（要连续执行，请选“重复长按动作”） |
| 状态条·自动关闭（新配了长按，长按只执行一次） | 这个按键已配置长按动作：按住会执行长按，而它只执行一次，“按住时连续执行”已关闭 |
| 状态条·自动关闭（其他） | 动作已变更，“按住时连续执行”已关闭 |
| 单击页说明句（未配双击 / 已配双击） | 单击在按下瞬间执行。/ 配置了双击：单击会稍等片刻（约 0.3 秒）以区分双击。 |
| 长按页说明句 | 长按约 0.55 秒后执行。 |
| 双击页说明句 | 配置后单击会稍等片刻（约 0.3 秒）以区分双击。双击不会连续执行。 |

## 2. 移动光标后按 OK 点击

### 2.1 目的

用遥控器把光标移到目标上（例如网页里的按钮、播放器的控件）后，希望按 OK 就是"点一下"，
而不是执行 OK 原来的动作。

### 2.2 语义

- 按键级开关，**默认关**；开启后：
  - **判定**：距上一次"用遥控器移动光标"不超过 **5 秒**（每次移动都会续期）；
  - **命中时按 OK**：在**按下沿立即**点击光标当前位置一次；
    **本次按压的单击 / 双击 / 长按都不执行**（松开也没有动作）；
  - **未命中或开关关闭**：按 OK 的行为与原来完全一致。
- 窗口内快速按两次 = 两次点击（是否成为系统双击由系统的双击判定决定）。

### 2.3 可用性

- 只对 **OK 键**提供（其他按键不显示该开关）；开关恒可用，没有置灰情形。

### 2.4 边界与失败路径

| 情形 | 行为 |
| --- | --- |
| 窗口过期后再按 OK | 走原来的动作（说明句已写明 5 秒） |
| 窗口内长按 OK | 只在按下沿点击一次，不触发长按动作 |
| 窗口内连按两次 | 两次独立点击 |
| 开关开但 OK 未配置任何动作 | 窗口外按 OK 无动作（与现状一致） |
| 断连 / 睡眠 / 退出 | 窗口清零；恢复后第一次按 OK 不点击（除非又移动过光标） |
| 用电脑鼠标（而不是遥控器）移动了光标 | 不算"遥控器移动"，不刷新也不清空窗口 |
| 点击位置的副作用 | 点击会激活光标所在窗口；点在桌面/文件夹空白处会取消选择——这是"点哪算哪"的固有行为 |
| 不检测"光标下是否可点击" | 直接点击即可；点不到可交互元素时通常没有后果 |

### 2.5 文案

| 位置 | 文案 |
| --- | --- |
| 开关名 | 移动光标后按 OK 点击 |
| 悬停 | 刚用遥控器移动过光标时，按 OK 会点击光标位置 |
| 常驻说明句 | 刚用遥控器移动过光标（5 秒内），按 OK 会点击光标位置。这时 OK 的单击、双击、长按都不会执行。 |
| 状态条·开启 / 关闭 | 已开启：用遥控器移动光标后，按 OK 会点击光标位置 / 已关闭：移动光标后按 OK 点击 |

- 不为每次点击加提示（点击是高频动作，逐次提示会打扰用户）。

## 3. 两个功能的共同原则

1. **显式开关**：功能默认不改变既有行为，由用户显式开启。
2. **置灰必给原因与恢复方式**，且不得指向同样不可选的选项。
3. **说明句只讲本页事实**，不承诺被置灰的功能；行为说明放在对应选项/开关的悬停里。
4. **配置变化自动收口到安全状态**（关闭）并告知，不偷改用户的选择。
5. 状态不跨连接/会话残留：断连、睡眠、退出后一律回到默认。
