- 日期：2026-10-25
- 参考：Mac「回眸」（行为与隐私边界，不复制 Swift 代码）
- 实施计划：[2026-10-25-reflections-windows.md](../plan/2026-10-25-reflections-windows.md)
- 真机验收：[Testing/WindowsReflections.md](../../Testing/WindowsReflections.md)

## 范围

开启「记录回眸」后，记录每次遥控器语音输入**实际写入目标输入框的新增文字**，按目标应用和本机日期整理。

同一页可另行开启「保存原始录音」，把每次语音会话的原始音频保存在本机，并支持播放、导出和删除。
录音只在「记录回眸」开启时才能打开；没有形成文字回眸记录的会话，只要录音成功，
就会以「仅录音」条目显示，不再静默留在磁盘上。录音失败或关闭不影响语音输入、文字上屏与文字记录。

暂不做：本地 Agent 或 MCP 访问、云同步、全文搜索、跨端导入、OCR/剪贴板兜底、
为读不到文字的应用注入或改私有数据。

## 用户可见行为

- 侧栏入口「回眸」，位置在「推荐」之后、「权限」之前；英文 `Reflections`。
- 个人中心提供回眸跳转：使用日历选中日期后显示「在回眸中查看」；单次语音排行每行可点击；排行底部显示「查看全部回眸」。
- 页头标题「回眸」，右侧「记录回眸」与「保存原始录音」两个开关，默认都关闭。开关立即持久化；关闭只停止新增，不删除已有记录，并取消正在进行的捕获/录音。
- 「保存原始录音」在「记录回眸」关闭时不可操作；重新开启「记录回眸」后沿用之前保存的录音开关值。
- 无记录且开关关闭：说明开启后会保存什么、已有记录不会因关闭而删除。
- 有记录：日期倒序，默认展开最新一天；应用栏固定「全部应用」，其余按最近使用排序，可展开为网格。
- 「全部应用」只显示最近 7 天；选中具体应用后显示该应用全部历史。
- 每条显示时间、目标应用真实图标与名称、文字；支持复制单条、删除单条、删除当前应用、全部删除。
- 有原始录音的记录额外显示「播放录音 / 停止播放」「导出录音」；每条记录只有一个删除入口，删除时文字记录与关联录音一起移到回收站。
- 没有匹配文字记录的录音单独归入「仅录音」，按目标应用和本机日期展示，默认展开最新一组；支持播放、导出和删除。录音带应用身份时显示真实应用名与图标；微信统一显示「微信」（英文 `WeChat`），不显示内部的 `Weixin`/`WeChat` 名称；升级前无身份的旧录音显示「未知应用」。
- 录音成功写入后页面在后台静默刷新，没有文字记录的新录音也会自动出现，不需要切换页面或重启应用。
- 复制成功图标短暂变对勾；失败显示「复制失败，请检查剪贴板权限后重试。」。
- 删除前弹确认框；成功走 Windows 回收站，可手动恢复。失败显示「删除失败，记录仍保留。请稍后重试。」，不覆盖原数据。
- 读取失败显示「读取回眸记录失败：…」与「重试」；归档读取异常显示非阻塞错误。
- 捕获失败、目标不可读、焦点变化、敏感输入框：静默跳过，不弹窗、不要求管理员权限。
- 录音读取或导出失败显示对应错误，不删除本地文件；播放中卸载页面或离开页面会停止播放。
- 页面首次进入只有读取超过约 150 ms 才显示「正在读取回眸记录…」；正常本机读取不出现加载卡。之后由新捕获触发的刷新在后台静默完成，不用加载卡替换已显示内容，也不让标题栏开关重新播放过渡动画。

## 捕获口径

- 以语音开始时的目标输入框文字为基线，语音结束后在有限时间内观察同一输入区域。
- 只保存基线与结束之间新增的一段连续文字；文字稳定后结算。超过 8000 字符的候选放弃。
- 语音开始时整个输入框已选中，或整个旧字段被替换（例如首次输入覆盖输入框占位文字）时，只保存替换后的新文字；局部选区替换仍拒绝，因为无法可靠取得选区偏移。
- 输入框在稳定窗口内被发送/清空时，保留最后一次已观察到的非空候选作为记录；占位文案（如「发送消息...」）不是听写内容，不能覆盖候选。
- 目标应用切换、焦点丢失、文字不连续、关闭开关都会取消或放弃本次候选。
- 连续语音时，上一段已观察到的候选在下一段开始前结算。
- 使用 Windows UI Automation（`ValuePattern` / `TextPattern`）；密码框、搜索框、地址栏、只读或设置类输入区域不记录。
- 微信 4.x 聊天主窗口等不暴露 UIA 文本的应用静默跳过。

## 数据与隐私

- 全部数据只保存在本机：`%LOCALAPPDATA%\SayAll\transcripts\v1`。
- 日文件：`<root>\<applicationKey>\<YYYY-MM-DD>.json`；图标缓存：`<root>\icons\<applicationKey>.png`。
- 原始录音：`<root>\audio\<sessionId>\original.wav` 与 `manifest.json`；格式为未压缩 WAV（PCM s16le，16 kHz，单声道）。
- 记录内容包含时间、应用键与名称、文字、来源、捕获方法版本；不保存输入框全文、前后文、窗口标题、文档名、URL、设备地址、进程完整路径或剪贴板内容。
- 录音只在「记录回眸」和「保存原始录音」都开启时写入；页面快照只读取 manifest（会话号、起止时间、时长、字节数、目标应用键与名称），不预载音频；播放时才按会话号读取 WAV。
- 录音不含输入框文字、窗口标题或设备身份；文件名与目录只使用随机会话号。manifest 记录目标应用键与名称，仅用于「仅录音」条目的归组与显示，不记录进程路径或窗口标题。录音不会自动上传。
- 应用身份使用稳定哈希键，界面只显示应用名称与图标。
- 日志只记录状态、原因、字符数、耗时等稳定字段，不写文字内容、窗口标题、路径或设备身份。
- 删除文件移动至回收站，不永久删除。
- 卸载/升级不得删除 `%LOCALAPPDATA%\SayAll\transcripts`。

## 平台差异

| 项目 | Mac | Windows |
| --- | --- | --- |
| 文本读取 | Accessibility API | UI Automation（`ValuePattern` / `TextPattern`） |
| 图标 | 应用 bundle 图标 | `PrivateExtractIconsW` 提取 64×64 PNG，失败用通用图标 |
| 原始录音 | AAC `.m4a`，独立开关；支持仅有录音的条目 | WAV PCM s16le；支持仅有录音的条目（以「仅录音」分组展示） |
| 删除 | 废纸篓 | Windows 回收站（`SHFileOperation`） |
| 入口 | 设置/统计页入口 | 侧栏独立「回眸」页；个人中心提供跳转 |

## 验收边界

自动化覆盖模型、存储、状态机、IPC 映射与页面逻辑。以下必须真机执行，不能用仿真替代：

- 真实前台输入框的 UIA 捕获、连续语音、焦点切换、关闭开关。
- RC001 与 RC003 分别验收。
- 真实应用图标、回收站恢复、重启保留、卸载/重装保留。
- 敏感输入框与不暴露 UIA 的应用静默跳过。
- WorkBuddy / 微信等文字捕获失败但录音成功的会话，以「仅录音」条目出现并可播放、导出、删除；旧录音归入「未知应用」。
