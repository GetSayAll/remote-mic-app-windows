# 无线麦 SayAll Windows 版 v1.0.0

首个正式版。把小米蓝牙语音遥控器 2（RC001）/ 2 Pro（RC003）变成电脑的无线麦克风，并为遥控器按键提供可自由配置的映射。

## 核心功能

### 无线麦克风
- 按住遥控器语音键说话、松开即出字：语音从遥控器实时传到电脑，直接进入当前输入框，无需额外麦克风。
- 兼容主流语音输入工具：豆包输入法、微信输入法、Vokie；也可选「其他工具」自定义「按住说话快捷键」。
- 连接页提供语音增益（0–24 dB）与语音设备选择（支持 VB-Cable 等虚拟声卡）。

### 全按键支持（可选开启）
- 开启后，遥控器上的**所有按键**都可被捕获与映射，包括返回 / 音量+ / 音量− 这些在 Windows 下默认不可见的按键。
- 系统级按键接管需要一次 Windows 授权；升级或覆盖安装保留已有授权，卸载后重装才需要重新授权。

### 按键映射
- 每个按键可映射为：键盘快捷键、鼠标动作（左右中单击、左键双击、滚轮、指针移动）、切换 / 启动应用（应用库）等。
- 「按住时连续执行」：按住不放可重复单击动作或重复长按动作。
- OK 键「移动光标后按 OK 点击」：刚用遥控器移动过光标时，按 OK 直接点击光标位置（按键级开关，默认关闭）。
- 应用库：扫描本机已注册应用、多选或全选保存，配置可导入导出。

### 首次设置向导
- 新装第一次打开会带你走一遍真实设置流程——连接遥控器、选择语音设备、选择输入工具、按住说话验证、再检查按键，每一步确认可用后才放行；中途退出，下次打开接着来。
- 已经用过的电脑不会被向导打断；想重走可在设置页点「重新运行向导」。
- 向导页脚提供「复制诊断信息」：流程卡住时一键复制报障信息。

### 设备与稳定性
- 自动扫描并连接已配对的遥控器；睡眠唤醒、断连后自动重连。
- 遥控器电量实时显示（设备上报即更新，断连或缺失时显示未知）。
- 「全按键支持」自动恢复：重启后设备晚到、升级 / 重装后的残留旧状态、功能中途断开，都会自动修复（受控复现：约 3 秒内恢复，无需重启应用或重连遥控器；系统里残留的旧接管也会被自动清理并重新接管）。
- 卸载更干净：自动释放占用运行数据的系统进程、清理运行时数据与登录启动项；设置、按键映射与使用统计按约定保留。

### 系统与界面
- 托盘常驻，支持登录时自动启动；Ctrl+W 随时把窗口收进托盘。
- 诊断日志单个文件不超过 10 MB、超出自动换新文件，且不写入任何访问凭据。
- 新增「几何鸭」应用图标，并作为新装默认：窗口、任务栏、托盘、开始菜单与桌面快捷方式会一起变化，安装包图标也一并更换。
- 在 Windows 11 ARM64 电脑上，「全按键支持」也可用。

## 改进（自上一个已发布预览版 v0.5.0）

- 修复应用窗口在前台时，按遥控器语音键唤不起输入法语音的问题。
- 修复更换输入工具或切换窗口后，第一次按遥控器语音键可能唤不起语音的问题：现在切换后立即按下也能一次唤起。
- 修复部分应用收不到遥控器映射按键的问题：此前替换后的按键只带虚拟键、不带物理键位，按物理键位识别的程序（键盘测试类网页、部分 Electron 应用）会漏掉这些按键，现在补齐了扫描码。
- 「全按键支持」的自愈更稳：重启电脑后遥控器晚一点唤醒、升级或重装后残留的旧状态、功能中途断开，都会自动恢复——不再出现开关显示已开启、按键却没反应的情况；系统里残留的旧世代按键接管也会被自动清理并重新接管（受控复现：约 3 秒内恢复，无需重启应用或重连遥控器）。
- 在 ARM64 电脑上，升级安装后若「全按键支持」暂时不可用，界面会说明原因与恢复方式，不再一直停在「正在启动」。
- 卸载更干净：卸载会清理运行时数据与登录启动项；设置、按键映射与使用统计按约定保留。
- 窗口默认大小与最小尺寸重新定稿：高缩放的大屏上不再局促，内容区留白与页面头部一并调整。
- 按键页整体改版（对齐 Mac）：遥控器实物图放大到看得清按键；「全按键支持」关闭时三张按键卡片置灰并说明怎么恢复。
- 安装或升级时不再弹出黑色命令行窗口；诊断日志不再写入访问凭据。
- 诊断日志单个文件不超过 10 MB，超出自动换新文件：报障要发的那份日志始终是当前文件，不会越攒越大。
- 卸载时不再出现「运行时数据未能立即删除、请重启或手动清理」的提示：即使遥控器还连着，也会自动释放占用运行数据的系统进程，把运行数据当场清理干净。
- 启动恢复上次选择的语音设备更稳：目标端点被占用时（常见于新版 VB-CABLE 的 16 Ch 端点），会自动改用同一台虚拟声卡上的另一个 CABLE 端点，不再报「设备被占用」。
- 修正「门内延迟」的时间单位错误：此前把毫秒当秒用，设置 150 毫秒会被实际放大成 150 秒——开启该延迟后按键会长时间无响应；现已按毫秒生效。

## 已知边界

- 安装器尚未配置 Windows 代码签名，首次运行可能出现 SmartScreen 提示。
- 「全按键支持」属于系统级按键接管，需要系统授权（需要授权时会弹出 Windows 授权窗口）；个别带防作弊保护的游戏可能按键失灵或游戏打不开，建议玩这类游戏前关闭该开关。
- 已经用过的电脑升级后不会自动进入首次设置向导，可在设置页点「重新运行向导」。
- 如果遇到「全按键支持」开着、按键却没反应：应用会自动尝试恢复；万一仍不行，把遥控器断开再重新配对一次即可。
- 遥控器语音键单次按住约 60 秒会在设备侧结束：之后需要松开再按才能继续说话（遥控器固件行为，应用侧无法延长）。
