## 对标结论（人工核对）

- **画布结构一致**：遥控器实物图居中 + 两侧按键卡 + 贝塞尔连线 + 按键锚点，
  布局表逐键移植自 Mac `RemoteMappingCanvas`（锚点/目标 Y 坐标相同）。
- **三态高亮一致**：实体按下中=橙色（背景 0.12/描边 0.65）、UI 选中=强调色
  （0.10/0.45）、普通=中性色；语音键卡片随语音会话点亮。
- **三列触发一致**：每键单击/双击/长按单元格，未设置显示"未设置"，
  已配置显示快捷键摘要。
- **编辑面板一致**：点单元格打开、滚动定位到可见、关闭（透传）选项 +
  预设芯片 + 自定义快捷键录入。
- **页脚一致**：监听状态 + 吞键/泄漏/触发计数、"锁定当前按键"开关、恢复默认。
- **差异（有意）**：Windows v1 不做打开具体 APP 动作与"允许连续快速按"开关
  （无对应后端能力）；语音键模式分段控件不迁移（Windows 已有按住说话快捷键
  设置，语义等价）；电量百分比不展示（ATVV 侧无电量特征）。
- **初始视口验证**：四页在默认窗口（1120×800）初始非滚动状态下全部元素
  位于视口内（UIA 遍历测得 连接 73/0、按键 105/0、权限 49/0、关于 43/0）。

## 边界

  RC003 开机即就绪）；吞键/手势注入的实体按键回路需用户按遥控器真机复核
