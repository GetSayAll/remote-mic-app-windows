# 常用语 · Windows 平台说明

> 适用读者：跨平台功能对齐与产品评审（Mac 侧规范要求本文件随功能落盘）。
> 实施记录与分批评审见 `docs/plan/2026-10-15-common-phrases-windows.md`；
> 真机验收见 `Testing/WindowsCommonPhrases.md`。

## 现状

- 能力形态与 macOS 对齐：会员能力（Plus / Pro），按键映射动作「打开常用语」；
  面板期间方向键 / OK **按下即插入**、返回键关闭；面板**不抢焦点**（插入落在打开面板前的输入框）。
- 插入机制：**剪贴板（OLE 全格式快照）+ Ctrl+V**；提交后约 250 ms 恢复原剪贴板。
  用户在此期间自行复制时**不回滚**用户内容（对齐 macOS Pasteboard 语义），
  但本事务持有的快照会被释放（不泄漏）。

## 与 macOS 的差异

1. 失败反馈为「**面板重新显示 + 提示行**」，并按原因分叉文案，输入框类 5 秒、其余 3 秒后
   自动收起面板；macOS 为独立 300×100 提示窗（3 / 5 秒）。文案见 `docs/product-copy.md` §7。
2. 面板是独立透明浮层窗口（Vue 第二入口），以 `WS_EX_NOACTIVATE` 保证点击不夺焦点。
3. 目标校验复用「聚焦输入框」的 UIA 硬门槛（可编辑、非只读、非密码框、非敏感字段）；
   无 UIA 树的应用按同一口径提示「光标不在输入框中」。
4. 备份格式本轮**不要求**与 macOS 互通。

## 边界（不可违反）

- 公开仓只保留接缝：动作 ID、浮层窗口宿主、认领与门控遮蔽、空壳 crate / 空壳 UI 导出。
  实现、内置内容与测试在私有包 `packages/windows-common-phrases`（构建期注入）。
  **缺私有组件时**：能力不可用、按键页隐藏入口、已保存绑定显示「打开常用语（当前不可用）」，
  不静默替换；稳定按键与语音不受影响。
- 会员门禁由会员组件下发的决策驱动；走查开关 `SAYALL_COMMON_PHRASES_ASSUME_MEMBER=1`
  仅开发 / 走查构建生效（精确 `"1"`；正式构建即使设置也忽略并留日志），正式包不可绕过会员。
- 常用语正文不进日志；剪贴板事务原位快照与恢复；按键认领发生手势识别之前、只基于运行时状态。
