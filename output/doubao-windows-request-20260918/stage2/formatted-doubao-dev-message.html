关于 Windows 版豆包输入法
语音快捷键接入的请求

一名普通用户

你们好，Mac 版豆包的语音输入可以被其他程序唤起，Windows 版却不行。真人在键盘上按语音快捷键能正常触发，但由程序发出的同一个按键会被忽略——Windows 不像 macOS 那样有「已授权合成输入」的概念，程序发出的按键都带注入标记，因此都会被过滤。这一点我们理解，也不想绕过。

希望能为 Windows 版豆包开放一个可被其他程序合法调用的语音输入入口。具体用哪种形式都可以接受：

  1. 把语音快捷键注册为系统级全局热键。这样遥控器、手柄、耳机等外设按下语音键即可直接唤起听写，不涉及模拟按键，你们现有的安全策略一行都不用改。这是我们最希望的方式。
  2. 提供一个命令行或本地接口（如命名管道、本地套接字），程序通过它启动语音输入，调用方由你们校验。
  3. 在设置里增加一个默认关闭的「允许模拟输入触发语音」开关，是否开启交给用户自己决定。

上述任意一种落地后，Windows 用户就能像 Mac 用户一样，用外设一键唤起豆包的语音输入。谢谢。
